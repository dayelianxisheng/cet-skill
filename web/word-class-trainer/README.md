# CET-4 选词填空词性训练

这是一个完全本地的静态网页，不需要登录、后端服务或私有站点权限。

## 使用

直接用浏览器打开 `index.html` 即可。

也可以在仓库根目录启动本地服务器：

```bash
python3 -m http.server 4173 --directory web/word-class-trainer
```

然后访问 `http://127.0.0.1:4173/`。

## 文件

- `index.html`：页面结构。
- `styles.css`：响应式样式。
- `app.js`：词性标注、候选筛选、最终选词和进度保存。
- `dataset.js`：本地题库导出的 42 套选词填空数据，共 420 个空、630 个备选词。
- `analysis.json`：网页启动时自动读取的预设分析，可以保持为空。
- `analysis.example.json`：分析 JSON 格式示例。

训练进度保存在浏览器 `localStorage` 中，不会上传到服务器。

页面顶部的“下一题转盘”会打开独立页面，从作文、听力、选词填空、长篇阅读、仔细阅读和翻译六类专项中随机决定下一项练习。

数据库原文没有保留段落换行。网页会按英文句子自动整理为短段落，只改变显示，不改动原文内容和空格位置。

当前题库没有可核验的选词填空答案键，所以网页只整理用户的推理结果，不显示伪造的正确率。

## 分析 JSON

页面作答只使用 `noun`、`verb`、`adj`、`adv` 等简单词性。`n-s`、`v-s`、`v-ing`、`v-ed` 等细分形式写入分析 JSON 的 `form` 或 `requiredForm` 字段，只在检查结果时展示。

使用本地服务器时，页面会自动读取同目录的 `analysis.json`。直接双击打开 HTML 时，可以点击“读取分析 JSON”选择任意分析文件。

每套解析可以使用数据库 passage ID、`YYYY-MM-卷号`（例如 `2020-09-1`）或完整试卷名称作为键。`words` 和 `blanks` 均为可选字段；没有预设答案时，省略 `answer` 即可。
