# CET-4 写作模板记忆训练

静态网页，包含：

- 五类写作模板的逐句、逐段和整篇朗读
- 本地数据库 42 条作文记录的分类、年份和关键词筛选
- 每道真题的完整英文题目、朗读与推荐模板跳转
- SMILEBAR 好处词块分组记忆与朗读
- 单句、整段和整篇打字默写及正确率统计；练习时隐藏方括号占位内容，并以 `xx` 统一代替

直接用静态服务器打开本目录即可：

```bash
python3 -m http.server 4175 --directory web/writing-template-trainer
```

浏览器访问 `http://127.0.0.1:4175/`。
