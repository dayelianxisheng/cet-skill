# CET-4 仔细阅读定位训练

鼠标优先的仔细阅读定位练习页，内含 78 篇去重文章和 390 道选择题。

## 练习流程

1. 在题干或选项中划取硬定位词。
2. 点击原文句子完成粗定位。
3. 在原文中划取能推出答案的最小证据。
4. 用“题目表达 ↔ 原文表达”记录同义替换。
5. 点击选项作答，再核对正确答案。

除可选的答案命题备注外，所有必填操作均可仅用鼠标完成。全文保留真实段落，并显示段号和句号。

## 本地运行

在仓库根目录执行：

```bash
python3 -m http.server 8000 --directory web/careful-reading-locator
```

然后访问 `http://127.0.0.1:8000/`。
