# CET-4 仔细阅读定位训练

鼠标优先的仔细阅读定位练习页，内含 2014–2026 年 150 篇去重文章和 750 道选择题。

## 练习流程

1. 在题干中拖选定位词，松开鼠标后自动加下划线并保存。可点击“清除题干划线”重画。
2. 点击原文句子完成粗定位。
3. 选项默认展开。对照原文时，可拖选选项里的词或短语保存划线，或在原文保存证据。
4. 点击 A–D 字母作答，再核对正确答案。

除可选的答案命题备注外，所有必填操作均可仅用鼠标完成。全文保留真实段落，并显示段号和句号。

## 本地运行

在仓库根目录执行：

```bash
python3 -m http.server 8000 --directory web/careful-reading-locator
```

然后访问 `http://127.0.0.1:8000/`。
