# 本地题库：仔细阅读专项

本流程用于用户拥有或明确授权的本地题库，当前处理 `question_type = careful_reading`。核心视角是考生实际操作顺序：**先读题干确定任务和定位线索，再回文章定位证据，最后打开选项比较**。

> 当前状态：已完成全库结构审计和答案核验。题库含42套、84篇、420题；答案覆盖420题，题型/证据段/证据句覆盖405题。统计由 `scripts/analyze_careful_reading.py` 复现，结果保存在 `data/careful_reading_statistics.json`。

## 零、实测结论与使用边界

- 证据段在本篇五题中只承载一道题：341/405，84.20%。五题全部落在五个不同证据段：49/69篇完整标注文章，71.01%。所以“题号大体顺序推进、常见一段一题”可作高优先级导航，但不是硬规则。
- 题干实词定位算法能可靠给出候选句的378题中，证据在定位句本句185题（48.94%）、前一句17题（4.50%）、后一句55题（14.55%）；其余121题相隔两句及以上（32.01%）。因此定位后默认读“本句＋前后各一句”，若未闭合题干关系再扩到整段，不能只读命中句。
- 405题的正确选项—证据映射都至少含一处非字面改写；569组映射中，519组为低词面同义改写、47组部分词面重合、3组字面一致。这说明同义改写主要发生在“证据→正确选项”，不能拿选项原词当首要定位工具。
- 上述“定位句相对位置”由题干非停用实词的段内IDF算法估算，不是人工逐题标注；27题因置信度不足被排除。报告概率时必须同时给出方法和覆盖，不能称为官方规律或绝对准确率。

## 一、为什么必须分三步

仔细阅读不能一开始就同时处理题干、全文和四个选项。这样容易出现：

- 被选项里的原文词吸引；
- 记住选项，却忘记题干问的对象；
- 找到相关段落，却没有找到真正回答问题的证据；
- 把“文章中正确的话”误当成“最能回答题干的选项”。

因此固定为：

`题干定任务 → 文章找证据 → 自己预判 → 打开选项比较`

## 二、阶段1：只看题干

此阶段不看A—D选项，完成三件事。

### 1. 判断题型

只使用以下八类，兼顾标志词和实际取证方式：

1. **事实细节题**：what / which / who / when / where / according to / says about；
2. **原因题**：why / reason / account for / because；
3. **方式过程题**：how / in what way / by what means；
4. **推断判断题**：infer / conclude / imply / suggest / most likely / probably；
5. **主旨目的题**：main idea / purpose / mainly about or discuss / best title；
6. **态度观点题**：attitude / view / tone / think of；
7. **词义指代题**：word or phrase ... mean / refer to / closest in meaning；
8. **例证目的题**：mention / cite / example / illustrate / quote。

题型标签决定后续证据范围，不能只靠关键词机械分类。

### 2. 标出“硬定位锚点”

格式使用 `【...】`，每处1—3词，原则上1处。优先级：

1. 人名、机构、地点、研究名、专有名词；
2. 数字、年份、比例、时间；
3. 引号词、题干指定词、少见具体名词；
4. 与其他题明显不同的对象。

以下内容通常不能作为硬定位：

- author / passage / study 等高频泛词；
- why / infer / according to 等命令词；
- good / important / people 等宽泛词；
- 整篇文章反复出现的主题词。

如果题干没有可靠硬定位，使用题号顺序和题型作为辅助，不强行制造 `【】`。

### 3. 标出“作答目标”

用Unicode下划线标记题干真正要求判断的内容，每处1—3词，可有1—3处：

- 问谁或什么；
- 问原因、结果还是态度；
- 时间、范围、否定和比较条件；
- `NOT / EXCEPT` 等会改变答案方向的词。

题干标记回答两个问题：

- `【】`：我先到哪里找？
- 下划线：找到以后我要核对什么？

## 三、阶段2：回文章定位

### 1. 定位优先级

按以下顺序找证据：

1. 题干明确指定的段落；
2. `【】`硬定位锚点及其词形变化；
3. 题号顺序：细节题通常大体按文章顺序排列，但只能作为辅助；
4. 同义表达和上下文逻辑；
5. 主旨、目的、态度题最后综合全文，不强行锁定单句。

### 2. 证据窗口

找到关键词后，不立即看选项。根据题型取证据窗口：

- 细节题：命中句＋必要时前后各一句；
- 原因结果题：同时保留原因句和结果句；
- 推断题：命中句＋支撑它的上下文，禁止脱离原文常识推断；
- 词义题：目标句＋前后解释、转折或例子；
- 句段作用题：被问内容＋该段主旨或前后逻辑；
- 主旨、目的、态度题：首段、转折处、各段主句和结尾共同判断。

默认最多保留三句，避免把整段都当证据；确需跨段时明确说明。

### 3. 证据标记

在核验阶段：

- 原文 `【】` 标出与题干硬定位相对应的位置；
- 原文下划线标出真正支持答案的关系、结论和限定条件；
- 原文没有直接复现题干硬定位时，不伪造对应，改为注明“同义定位”。

## 四、阶段3：先预判，再看选项

定位证据后，先用一句短语写出“最小答案命题”，再比较A—D。

最小答案命题只保留：

`主体 + 核心关系 + 必要限定`

例如：

`学校无需付费参加`、`果汁缺少纤维`、`作者持谨慎支持态度`。

预判不是要求复述原文，而是防止被选项牵着走。主旨题可以预判中心矛盾或作者目的；推断题预判必须比原文保守。

## 五、阶段4：比较四个选项

逐项核验以下八个维度：

1. **主体**：谁做了什么；
2. **核心关系**：动作、状态、观点是否一致；
3. **对象或结果**：作用对象和结论是否偷换；
4. **因果方向**：原因和结果是否倒置；
5. **时间与条件**：过去/现在、必要/可能、特定条件是否一致；
6. **范围**：some / many / most / all，局部还是整体；
7. **极性与程度**：肯定/否定、可能/必然、缓和/绝对；
8. **问题相关性**：选项即使符合文章，是否真正回答题干。

正确答案标准：**被证据直接支持或合理保守推导，并且是四项中最完整回答题干的一项。**

## 六、干扰项分类

只保留便于考生复盘的八类：

- 原词复现，但逻辑不支持；
- 主体偷换；
- 对象或概念偷换；
- 范围扩大或缩小；
- 因果倒置；
- 时间、条件或程度错位；
- 过度推断或绝对化；
- 文章中正确，但答非所问。

一道错题只标主错因，必要时附一个次错因，不堆叠标签。

## 七、面向用户的默认练习版式

### 模式A：题干预处理

```text
模式：题干预处理（未读取选项和答案）

46. {原题干}
- 题型：细节题
- 定位：{带【】的题干}
- 核对：{带下划线的作答目标}
```

### 模式B：定位练习

```text
46. {带标记题干}

你的定位段落：____
证据句：____
最小答案命题：____
```

不显示答案，不替用户填写空白。

### 模式C：完整做题

固定顺序：

1. 文章；
2. 带题型和定位标记的题干；
3. A—D选项；
4. 用户按 `46A 47C...` 作答。

答案揭示前不得在文章中标出正确证据，不得突出正确选项。

### 模式D：答案核验

```text
## 46

题型：{类型}
用户答案：{字母}
正确答案：{字母}

定位路径：
{题干硬定位 → 段落 → 证据窗口}

原文证据：
{带两级标记的证据句}

最小答案命题：
{一句短语}

选项比较：
- A：{支持/错因}
- B：{支持/错因}
- C：{支持/错因}
- D：{支持/错因}
```

## 八、做题人的时间策略

- 先读五道题干，不先细看选项；
- 每题只完成“题型＋定位锚点＋作答目标”，控制在约10—15秒；
- 阅读文章时遇到定位锚点，在段旁写题号；
- 找到证据后先形成最小答案命题，再看选项；
- 单题证据不明确时先标记候选段，不在一个题上停留过久；
- 主旨、目的和态度题通常最后处理。

以上时间仅作为训练建议，不作为固定能力判断标准。

## 九、答案隔离

- 题干预处理阶段只读 `questions.stem_text`；
- 定位练习阶段可读文章，不读 `options` 和 `answer_keys`；
- 完整做题阶段可读选项，但不读 `answer_keys`；
- 用户提交答案或明确要求解析后，才读取 `answer_keys`；
- 不能根据答案倒改题干定位标记。

## 十、数据核验与迭代要求

1. 答案导入必须以题干和A—D内容识别真实试卷，不能只信来源套号；本库曾发现来源的第1/2套编号互换。
2. 题干和四个选项允许标点、空格、单复数等高相似度差异，也允许来源选项顺序互换；必须先做四项内容对齐，再把来源答案字母映射回本地字母。
3. 任何已有答案冲突都拒绝自动覆盖并进入人工审计。
4. 统计只使用有完整证据标注的405题；缺失标注的15题仍可用于答案覆盖和题型标志词统计。
5. 每次增加题目或修改标注后重跑统计脚本；覆盖率、算法口径或概率变化时同步更新本文件。
