# Local lexical data

The normalized files in `normalized/` are generated by
`scripts/import_lexical_resources.py` and are intentionally ignored by Git.
The raw repositories in `data/external-sources/` are also ignored.

Sources are pinned to:

- `https://github.com/lnkDrop/Match-Root.git` at
  `103df58c17f5600968f8e05c88fc997c50e15dff`
- `https://github.com/kajweb/dict.git` at
  `3992bcb94c800a2fd38a9fd6ff95b2353e755363`

Neither repository contained a license file at the pinned revision.  The data
is therefore kept for local use and is not included in commits or pushes.

Run:

```powershell
python scripts/import_lexical_resources.py --export-data --apply
```

This exports normalized JSONL files and imports the same records into the local
`cet4` MySQL database.  The importer records source URL, commit SHA, and license
status in `lexical_sources`.
